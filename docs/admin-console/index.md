# Admin Console

!!! note "Coming soon"
    Documentation for the admin console is coming soon.

Sandloom includes an optional console for the platform owner and the operations team:
users, organizations, billing, audit and service health. Until this section is ready, its
source and setup notes are in
[`admin/`](https://github.com/Sandloom-dev/sandloom/tree/main/admin) in the repository.

The console's screens build on your modules, so start with the
[quickstart](../getting-started/index.md).
