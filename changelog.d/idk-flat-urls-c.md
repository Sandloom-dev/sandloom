### Added

- **`sandloom.driverkit.process_config.process_instance(capability, name="default")`** (idk-flat-urls-c). A driver package imports only `sandloom.driverkit` and so cannot read `Settings`; a process that boots no application (the Celery driver's importable app) reads an instance's options through this function. It returns the instance as the application resolves it (`Settings`, the composition's selection, `INFRA` over it, the options each installed driver still takes from a flat setting) as an `InstanceConfig` copy, or `None` when the configuration declares none. It opens nothing; an invalid configuration stops the process with the configuration error, and a driver of the configuration that cannot be loaded raises `RuntimeError` with the reason. Additive: no existing name changes.
