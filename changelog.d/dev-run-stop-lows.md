### Fixed

- **`sandloom dev run` stops its worker and beat once, and no longer leaves them behind** (dev-run-stop-lows). Follow-up to the background worker and beat of `dev run`. Every stop path except Ctrl-C sent each background process SIGTERM twice: a Celery worker logged its warm shutdown twice, and the beat released its lease twice (an error, and a lease that stayed for about 19 s, so the next beat waited). A process is now asked once. A Ctrl-C between the start of a background process and its registration no longer orphans it (it has a session of its own); an interrupt or an error right after the start kills it. The wait on the app server has an end: past the stop's 20 s deadline a server that never finishes its shutdown is killed, and the background processes are stopped after it. The app server ignores SIGHUP (it shares the terminal's process group, and uvicorn does not handle it), so a closing terminal reaches `dev run` first and everything stops in order.
- **The worker and the beat of `dev run` run the task queue instance the periodic jobs name.** A composition whose only task queue is not `default` failed to start the worker. With one instance named (and `SANDLOOM_WORKER_TASKQUEUE` unset) both get it; with several, `dev run` warns and keeps `default`.
- **`dev run` reads `INFRA` of `.env` as the worker does.** A line such as `INFRA='{...}' # my queue` was not read, so a macOS worker kept the `prefork` pool and refused to start. The `solo` pool also yields to a `worker_pool` or a non-`celery` driver that the composition's `DEFAULT_INFRA` selects.
- **A stale `dev run` marker, and leftovers, are checked tighter.** The marker records when its process started: a pid the system reused (after a reboot, say) is no longer taken for a running `dev run`. A leftover counts as the recorded process only within 2 s of its recorded start (was 10 s), is checked again before SIGKILL, and the wait after the kill is bounded. The "started" line of the worker and the beat is printed after they started and names only those that did.
