### Breaking changes

- **The volatile event bus names say `broadcast`, not `redis`** (redis-out-names). `EVENT_BUS_REDIS_SEMAPHORE_LIMIT` is now `EVENT_BUS_BROADCAST_SEMAPHORE_LIMIT` (same meaning, default `100`); startup fails while the old name is set, and the error names the new one. The event bus counter `redis_reconnect_attempts` in `/diagnostics` is `broadcast_reconnect_attempts`, and the Prometheus counter `sandloom_redis_reconnect_attempts_total` is `sandloom_broadcast_reconnect_attempts_total`; the bundled Grafana dashboard queries the new name. The old names have no alias. The text of `SANDLOOM-R014` names a backing service instead of PostgreSQL and Redis; its fix is unchanged. See [Upgrading to 0.7.0a15](https://sandloom.dev/docs/operate/upgrade/#upgrading-to-070a15-the-volatile-event-bus-names-say-broadcast).
