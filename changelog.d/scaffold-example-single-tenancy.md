### Fixed

- **The tests of the sample module `sandloom new` writes, and of every `sandloom add module`, pass in an app run with `TENANCY_MODE=single`** (scaffold-example-single-tenancy). Two of them failed with `403 tenant_mismatch`, because they minted a token for a random tenant and `single` binds `SINGLE_TENANT_ID` only. The scaffold still reads no setting: the written tests ask the app's own settings (`sandloom_core.settings`) at run time which tenant to bind, a fresh one under `multi`, `SINGLE_TENANT_ID` under `single`. In `single` the isolation test asserts the `403` `tenant_mismatch` of a token naming another tenant, where `multi` asserts an empty list. A module added with `--no-tenant` is unchanged. Apps made before this fix: replace `as_user(tenant_id=uuid4())` in the module's tests with the tenant the mode expects, as the new scaffold does.
