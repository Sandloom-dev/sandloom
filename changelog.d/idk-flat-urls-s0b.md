### Changed

- **The test harness needs no `CACHE_URL` / `BROKER_URL`** (idk-flat-urls-s0b). `SANDLOOM_TEST_CACHE_URL` and `SANDLOOM_TEST_BROKER_URL` keep their names and are merged into `INFRA`: the `default` cache (`url`) and task queue (`broker`) whose driver takes that url from the flat setting (created when `INFRA` names none), and every other declared instance on the same Redis server and database as that default; an instance on another database or server keeps its url, and a declared celery `backend` follows a replaced `broker`. They are copied onto `CACHE_URL` / `BROKER_URL` only where `.env.test` still sets those. `sandloom_cache` and `real_uow_client` read the cache url of `INFRA`'s `cache.default` (the flat `CACHE_URL` is the fallback), and the self-connection check and the beat check read the urls of `INFRA` instances. Additions only: `sandloom.sdk.testing.resolved_cache_url` (the cache url a run uses, for `override_instance`), and in `sandloom.core.testing` `workers.infra_with_overrides` and `families.INSTANCE_URL_OPTIONS`.
