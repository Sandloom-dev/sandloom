### Changed

- **The admin console is packaged with one exact Node, so its `.gz` and `.br` files are the same bytes on every machine** (console-build-node-pin). The compressed assets come from the zlib and brotli inside Node, and two Node builds wrote different bytes under the same file names. `admin/.nvmrc` and `engines.node` now name Node 22.21.1 (a test keeps them equal) and the CI `setup-node` steps read `.nvmrc`. `npm run package` and `package-console.mjs` refuse any other Node, `npm run build` only warns, and the `admin.yml` job packages again and fails when the committed console changes. The gzip header's OS byte, the one byte the build OS changed (19 on macOS, 3 on Linux), is now always 255, so the five `.gz` files were repackaged once with that byte changed. No upgrade step.
