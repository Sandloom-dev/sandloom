### Changed

- **CI runs less of what another job already ran** (ci-dedup-2a). A `kernel` change area (the backend paths less the bundled modules `src/sandloom_*`) selects the kernel lanes and both driver lanes, so a module-only PR skips them. The admin filter is a positive path list. The kernel-without-redis job collects every kernel suite without Redis, Celery and kombu, runs the files `tools/ci/no_redis_pending.json` names (read at run time) and its two ratchet files, and `test_no_redis.py` scans the kernel tests for Redis or Celery imports. The batteries run deselects tests that `backend-tests` or `workflow-policy` run whole; `workflow-policy` gains the agent-context, guarantee-ledger, Pages-workflow and generated-docs tests. `docs.yml` skips the second run of the prose lint and code check, `admin.yml` drops `contracts:check` (the `admin-contracts` job runs it), and the celery lane no longer reruns the celery-free `test_beat_lease.py`. `tools/agent_reference.py ci` prints brace globs and `<dummy>` for throwaway credentials to stay under its size cap.
