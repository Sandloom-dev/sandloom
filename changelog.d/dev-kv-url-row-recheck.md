### Changed

- **`driverkit.shared_endpoints.redis_endpoint` reads the database as redis-py does** (dev-kv-url-row-recheck). A non-empty `?db=N` now wins over the path (the shared-database startup warning followed the path, so a URL with both named the wrong database), the path loses every `/` and its percent-escapes (`/%33` and `/1/5` are databases 3 and 15), and a path that is no number is database 0, as before. `DEFAULT_REDIS_PORT` (6379) is now a public name of the module, which `sandloom-redis` imports instead of declaring its own. The host keeps a trailing dot: `cache.local.` and `cache.local` are two endpoints, since the connection keeps the dot and the resolver may complete the second differently. `sandloom dev up --services external --kv-url` compares the keyed servers the same way (host and port as the stack's parser fills them, the dot kept): another spelling of one server is not checked again, a trailing dot is, and a row pair that holds keys there is replaced or the `up` is refused before the state is saved. No upgrade step.
