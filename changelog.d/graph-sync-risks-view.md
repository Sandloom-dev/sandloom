### Added

- **`sandloom graph --runtime-risks` and a Coupling tab show synchronous contract coupling** (graph-sync-risks-view). `graph [MODULE] --runtime-risks` appends a table to the text map: each module, the modules it requires a contract from (`(optional)` marked), its depth (the longest chain of contract hops it can start; `cycle` for a module in a contract cycle, `N + cycle` for a chain that ends in one) and its fan-in, riskiest first, then the longest chain and the most depended-on modules. The numbers are the `data.sync_coupling` section `graph --format json` already carried: an upper bound from declared requires, not measured calls. The flag is text only; with JSON, Mermaid or HTML, or with `impact`, `diff`, `sequence` or `state`, it is a usage error (exit 2). The HTML viewer (`sandloom explore`, experimental) gets a Coupling tab with the same rows, and a module's inspector shows its depth, fan-in and longest chain. `docs/ai/architecture-graph.md` explains how to read the table and which chains to replace with an event or a projection. Without the flag, the text output is unchanged.
