### Changed

- **Forty-nine more kernel tests run without Redis** (idk-gated-tests-3a). The replaceability and trust-row topologies run on the kernel's `memory` cache and the `database` security store (shared through PostgreSQL, so a revocation reaches every process of a split topology) where `sandloom-redis` is not installed, and on the Redis drivers where it is. The `sandloom generate` boot of the generated-app tests (`test_sdk_generators.py`, the docs generator check) selects the `memory` drivers through `INFRA` (`redis_free_infra_env` in `sandloom.core.tests._root_support`); the tasks of the generated "everything" app need a task queue and join it only where `sandloom-celery` is installed. `test_streams_event_bus.py` patches the dedupe inbox's cache with `InMemoryCache`, as `test_transport.py` does, instead of a Redis client that nothing reads any more. `tools/ci/no_redis_pending.json` lists 51 tests and `CEILING_TESTS` is 51. Test-only: no behaviour changes.
