### Breaking changes

- **The volatile event bus driver is `broadcast`, not `redis`** (eventbus-broadcast-driver). The `eventbus` driver that runs over a `broadcast` instance talks to no service of its own, so it is named after the capability it runs on. `INFRA={"eventbus": {"default": {"driver": "broadcast"}}}` replaces `"driver": "redis"`, and `EVENT_BUS_BACKEND=broadcast` replaces `redis`. The driver no longer declares the `redis` package as a requirement and imports nothing of Redis. The old spelling still loads for this release: it resolves to `broadcast` and startup logs one WARNING per instance naming the new spelling. The alias goes away in a later release. `RedisEventBus` is `BroadcastEventBus` and `RedisEventBusProvider` is `BroadcastEventBusProvider` for code that imports them from `sandloom.core.eventing`. See [Upgrading to 0.7.0a15](https://sandloom.dev/docs/operate/upgrade/#upgrading-to-070a15-the-volatile-event-bus-driver-is-broadcast).
