### Fixed

- **The files a `sandloom docs recipe` tells an app to write pass `sandloom test` as written** (recipes-ruff-clean). Since `sandloom test` runs `ruff check --no-fix` and `ruff format --check` (it never writes), seven recipe files failed the lint step of the `app-recipes` job: the `<app>.shared.contracts…` imports stood below the `sandloom.sdk…` ones although the generated app's ruff configuration sorts both as one first-party block in alphabetical order, and two `# sandloom: advanced <reason>` import lines were wider than 88 columns (`UnitOfWorkRequiredError`, `publish_event_versions`), which isort wraps. The recipe text now orders the imports as ruff does and keeps those lines short. `tests/sdk/test_sdk_recipes_ruff.py` renders every recipe's files into an app skeleton with the ruff tables of `sandloom new` and runs both checks.
