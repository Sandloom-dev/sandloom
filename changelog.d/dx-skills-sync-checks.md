### Added

- **`sandloom test` says when the agent files are older than the package** (dx-skills-sync-checks). It prints one info line, "agent files are from an older sandloom: run `sandloom add skills`", when the hashes in `.sandloom/agent-files.json` differ from the installed sandloom's skill and module-author contract templates, or the record lacks a skill the package ships. It is no failure and makes no network call; an app without the record gets no line.
- **The docs checks cover the agent files `sandloom new` ships** (dx-skills-sync-checks). The docs code check (D1-D4) and the stale-symbol lint now also scan `src/sandloom/core/cli/templates/**/*.md`, and the docs code check is a pre-commit hook. Tests check that every recipe, `sandloom` command and error code the skills, the module-author contract and the API cheat-sheet name exists, and that the beginner table in a new app's `AGENTS.md` is exactly the union of the `__beginner__` names.
