### Security

- **The broker probe no longer chains an error that holds the broker password** (kernel-safe-urlsplit). `probe_broker` read the broker url with a bare `urlsplit`; for a url with a character that Unicode-normalizes to `:` `/` `?` `#` or `@` (U+FF1A, say) the `ValueError` of `urllib` carries the whole netloc, `user:password` included, and `BrokerUnreachableError` is raised `from` it, so a traceback printed it. The probe now reads the scheme through `connection_policy.scheme_of`, which raises one fixed message. `connection_policy` reads every url through `sandloom.driverkit.url_split.split_url` instead of a private copy; its message now starts with "the url cannot be parsed" (it said "a broker or backend url cannot be parsed"). The package needs a kernel that has `sandloom.driverkit.url_split` (already required by the Redis package). No other upgrade step.
