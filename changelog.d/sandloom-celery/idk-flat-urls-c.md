### Changed

- **`celery -A sandloom_celery.worker` reads its broker from `INFRA`, not from the `BROKER_URL` variable** (idk-flat-urls-c). The importable app (`app`, `celery`, `celery_app`; for `celery inspect`, `call`, `status` and Flower) is built, on first use and with no import side effect, from the options of the `default` task queue as the application resolves them: `Settings` (environment and `.env`), the composition's selection, `INFRA` over it. State the broker as `INFRA='{"taskqueue":{"default":{"broker":"redis://..."}}}'`. Without one the lookup raises `AttributeError` naming `taskqueue.default.broker`, and a `default` task queue that is not the `celery` driver is refused with a message saying so. The module no longer reads `os.environ["BROKER_URL"]` (`BROKER_URL_ENV` is removed). A stray `BROKER_URL` in the environment still cannot replace the broker of a worker or a beat: `sandloom worker` and `sandloom beat` keep hiding Celery's own `BROKER_URL` option variable for the run. Upgrade: a service that ran `celery -A sandloom_celery.worker ...` with only `BROKER_URL` set (and no `INFRA`) keeps working while the flat `BROKER_URL` setting exists, because the kernel still fills the broker from it; the setting goes away in a later release, so put the broker into `INFRA` now.
- **`backend` has no default and is documented as optional** (idk-flat-urls-c). Sandloom never reads a task result (`task_ignore_result` is on), so an instance that states no `backend` runs with no result backend. The kernel still fills a missing `backend` from `CACHE_URL` until that setting is removed in a later release: leave `backend` out of `INFRA`, and do not rely on the fill. The importable app now takes the same `backend` as the provider's `default` instance (before: always none).
- **The importable app needs the kernel's configuration to be valid.** Reading `INFRA` loads `Settings`, so an invalid configuration (for example a missing `DATABASE_URL`) stops `celery -A sandloom_celery.worker` with the configuration error, where it used to start from `BROKER_URL` alone.
