### Changed

- **The kernel CI lane is two parallel jobs, and the PR gates run less that cannot change** (ci-speedup). `kernel-without-batteries` keeps the kernel, SDK, architecture and replaceability suites with `sandloom-redis` installed (and deselects the 82 s `test_nested_units_match_the_oracle_at_length`); the new `kernel-without-redis` runs the same suites without the Redis client and drivers (with `tests/architecture/test_no_redis.py` only, plus the oracle test) and the asyncpg SQLite boot, in parallel. `backend-static` runs the architecture tests on 4 xdist workers, with the PostgreSQL service their workers need. `docker-build` follows a new `image` change area (what the production image copies, not tests), `benchmarks/dx` no longer runs `benchmarks-security`, `packages.yml` keeps only the slow wheel matrix of the module subsets (the other two run in `backend-tests`), and the pre-push `backend-full-tests` hook runs `-m "not slow"` like the PR lane. No test or check was dropped: each still runs in at least one job of a PR's CI.
