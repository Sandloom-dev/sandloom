I added a nightly task that deletes invitations that expired more than 30 days ago, in every organization and whatever their status. `uv run sandloom test` passes, including lint, types and the migration-drift check.

**1. What I built**
- **Task:** `teamhub/modules/invites/tasks.py` holds `purge_expired_invitations`. It runs at 03:00 UTC, and the beat hook was generated by `sandloom add task --periodic`.
- **Safe to run twice:** each run deletes by a condition (`expires_at < now − 30 days`), so a repeated or overlapping run finds nothing left to delete.
- **Safe if a worker dies:** it deletes in batches of 1000, each batch in its own committed unit. The task is set to redeliver if its worker dies (`acks_late`, `reject_on_worker_lost`), and the rerun picks up the remaining rows.
- **Tests:** `teamhub/modules/invites/tests/test_tasks.py` covers four things:
  - It deletes only invitations past the 30-day cutoff, across organizations.
  - It deletes pending, accepted and revoked ones alike.
  - Two runs through the real task commit correctly, and the second deletes nothing.
  - The nightly schedule is registered.

**4. Where I guessed**
