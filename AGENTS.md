# Sandloom Framework — agent map

Sandloom is a Python backend framework for AI-driven development. One codebase deploys as a monolith or as
microservices by configuration alone (`SANDLOOM_MODULES`, `SERVICE_BINDINGS`); moving a module's
live data to its own database is a separate offline step (`sandloom migrate extract-module`).
Production backends: PostgreSQL + Redis (+ local files, SMTP).

This file is a map, not the manual. **Before editing, read the contract for the code
you touch** (nearest wins):

| you are changing | read first |
|---|---|
| a business module: `src/sandloom_<module>/`, `examples/*/…/modules/` | `src/sandloom/AGENTS.md` (module-author contract) |
| the kernel: `src/sandloom/core/`, `src/sandloom/sdk/`, `src/sandloom/shared/` | `src/sandloom/core/AGENTS.md` (kernel-contributor contract) |
| deploy profiles, gateway, compose | `deploy/AGENTS.md` |
| the admin console (React) | `admin/AGENTS.md` |

## The one rule

**Modules are atomic and isolated.** A business module and its tests import only public
`sandloom.sdk` modules (no leading underscore), the generated contract stubs and DTO copies
(`sandloom.shared.contracts.*`, an app's `<app>.shared` / `CONTRACT_DTO_PACKAGES`) and
their own package; an installed module package (`sandloom_identity`, a third party's) is another
module. Cross-module work goes through typed events (`Event`, `@on`), contracts (`@contract`,
`Contract(REF)`), projections or sagas, never an import.

## Non-negotiables (each enforced — the failure prints a code: `uv run sandloom explain <code>`)

| rule | enforced by |
|---|---|
| imports: `sandloom.sdk` + stubs/DTOs + own package; no sibling module, no function-local import | `sandloom check` C001, C002, C005, C013, C021 |
| never `db().commit()` / `rollback()` — the unit owns the transaction; `db()`, `publish()`, `record_audit` only inside a unit | `sandloom check` C006, C007; SANDLOOM-R002 |
| a route is authenticated (the default of `module_router()`) or declares `public(reason=)`; nothing else to declare (model E) | SANDLOOM-B008 at startup; route snapshot SANDLOOM-T001 |
| tenant rows inherit `TenantScoped`; `sandloom migrate new` writes the RLS policy; raw SQL needs `unscoped()` | `sandloom check` C014, C015, C024; SANDLOOM-T006 |
| an `Event` class: versioned channel, wire fields, one producer; same `.vN` only gains optional fields | SANDLOOM-B015, SANDLOOM-T005, C025 |
| a `@contract` class: stateless, async, wire types; DTOs in its own `schemas`, copied by `sandloom generate` | SANDLOOM-B018, C012, SANDLOOM-T004, SANDLOOM-T007 |
| an `@on` consumer takes exactly its event; billing atoms state `of=` | SANDLOOM-B016; SANDLOOM-B017, C027 |
| endpoints in `api`, SQLAlchemy only in `models`/`services`, pure `schemas`; no backend SDK or raw client | `sandloom check` C009–C011, C003, C004 |
| the public surface and the beginner tier (kernel work) | SANDLOOM-T008, SANDLOOM-T009, `lint-imports` |

Rules **no check enforces yet** (per-org `TenantScoped`, effect dedupe in tasks and commands, `.v2`
dual-publish, security revocation, commands as saga steps; agents skip them most): `src/sandloom/AGENTS.md`.

## Golden path (run from the repository root)

```bash
docker compose -f deploy/compose/test.yml up -d --wait  # test Postgres :5433, Redis :6380
uv sync                                                 # pinned dev tools (ruff, mypy, pytest)
uv run sandloom add module <name>                # also: sandloom add event|contract|consumer|saga|projection <module> …
uv run sandloom migrate new <name> "<message>"   # autogenerated revision in the module's chain, RLS included
uv run sandloom generate                         # snapshots, contract stubs + DTO copies, event schemas
uv run sandloom test <name>                      # module tests, fast suite (parallel), static gates
uv run sandloom test --full                      # once, at the end: full parallel suite + gates
```

- **`sandloom generate` writes** the generated files (a breaking change writes nothing; `sandloom
  add` runs it last). **`sandloom test` is the gate, never writes:** ruff, format, mypy, `sandloom
  check`, architecture tests, `lint-imports`, API baseline, generated files. No serial `pytest -q`.
- Use your own test DB and Redis on a shared machine: `SANDLOOM_TEST_DATABASE_URL`,
  `SANDLOOM_TEST_CACHE_URL`, `SANDLOOM_TEST_BROKER_URL`, `SANDLOOM_TEST_OWNER`.
- Changing an AGENTS.md, a rule or skill, a generator or the public API? Re-run the DX eval
  (`benchmarks/dx/README.md`; `run_eval.py triggers` says when).

## Public API cheat-sheet (`sandloom.sdk`; any other signature: `uv run sandloom docs <name>`)

The 29 beginner names, exact signatures; any other name's import carries `# sandloom: advanced <reason>`.

```python
# from sandloom.sdk import ...
register = define_module(__name__, *, version="0.1.0", consumes=(), capabilities=(),
              depends_on=(), setup: Callable[[ModuleAPI], None] | None = None, ...)  # __init__.py
class Note(TenantScoped, Base): ...        # tenant_id column + automatic filter; Base alone: global
    id: Mapped[UUID] = mapped_column(primary_key=True, default=new_id); created_at: Mapped[CreatedAt]
db() -> AsyncSession                       # the running unit's session: add/flush, never commit
router = module_router(*, prefix=None, tags=None, tenant="derive", dependencies=())  # api.py
public(*, reason: str, issues_tokens=False) -> Depends   # dependencies=[public(reason="...")]
user: CurrentUser                          # the caller (UserContext: .user_id, roles, claims)
class NoteCreated(Event, channel="notes.note.created.v1"): note_id: UUID; tenant_id: UUID
await NoteCreated(...).publish(*, database=None)   # outbox of the running unit
@on(E, *, name=None, durable=True, required=True, dead_letter=True, start_from="earliest",
    group=None, database="default", tenant="derive")          # async def f(event: E) -> None
@contract("<m>.<name>.v1", *, database=None)                  # stateless class, async methods
@command(*, idempotency_key: str, idempotency_scope=(), database=None, risk: "money" | None = None)
quota = Contract(STATS_QUOTA_V1)           # REF from the generated sandloom.shared.contracts.<name>

require(policy, *, status_code=None)       # dependencies=[Depends(require(OrgRole("admin")))]
Subscribed(statuses=None, *, of: Account, claim_key="subscription_status")   # claims, zero I/O

              status_code=None)            # loader: async (id, db) -> entity | None

              resource_id=None, data=None, required=None, database=None)   # sync, in a unit
await on_commit(callback, *, database=None)                 # runs only after COMMIT

        **claims) -> tuple[UUID, dict[str, str]]           # (user_id, auth headers)

              core=None) -> int                   # drives the real consumer runtime
```

## Looks wrong but is intentional

- `tests/architecture/_fixtures/*.py.txt` — deliberately broken modules the
  analyzer self-tests scan (data, not importable, never shipped).
- `sandloom/shared/contracts/*.py` (stubs, `*_dto.py` DTO copies), `sandloom/shared/events/*.json`
  and each `module.snapshot.json` are written by `sandloom generate`: never hand-edit them.
- `ORM_LEAKAGE_BASELINE` in `test_api_no_orm_leakage.py` — a ratchet: remove entries only.
- `FakeStripeClient` is the default PSP outside prod and rejects unsigned webhooks (sign
  test payloads with `sandloom_billing.psp.sign_stripe_payload`).
- `/health/simple` is process liveness; `/health` and `/ready` answer 503 when degraded.
- Error handling is app-wide (`sandloom.core.http.error_handlers`); modules register none.
- Duplicate event deliveries happen (at-least-once by design); `@on(durable=True)`, the
  default, claims each envelope id once.
