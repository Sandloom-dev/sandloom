## Проблемы с тестами

### Критические ошибки

1. **Многие тесты пытаются мокать несуществующие функции**:

   - `decode_jwt_token` не существует в permissions.py
   - `get_user_roles_and_permissions` не существует в permissions.py
   - Неправильные mock объекты

2. **Проблемы с async тестированием**:

   - Несколько тестов не правильно работают с asyncio
   - Mock объекты не subscriptable

3. **Дублирование тестов**:
   - test_permissions_simple.py
   - test_permissions_complex.py
   - test_permissions_fixed.py
   - test_tasks_simple.py
   - test_tasks_complex.py
